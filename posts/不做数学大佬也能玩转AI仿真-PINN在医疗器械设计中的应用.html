医疗器械设计里的经典难题

仿真（有限元FEA、CFD）是医疗器械设计的标配：散热、血流、结构强度、电磁场。

但传统仿真有三个痛点：

**痛点1：算得慢。** 一个精细的CFD仿真跑几小时到几天。

**痛点2：参数要人调。** 边界条件、材料参数，靠工程师经验试。

**痛点3：数据不足。** 真实验证数据贵（动物实验、临床试验），样本少。

PINN正好解决这些。

PINN是什么（人话版）

传统神经网络：只学「输入→输出」的数据关系，物理规律不管。

PINN：在损失函数里**加物理约束**。

比如你要预测血流场：

• 传统AI：喂「入口条件→流场」数据，纯数据学习

• PINN：喂数据 + 强迫输出满足纳维-斯托克斯方程（流体物理规律）

**好处：** 数据少也能学得准（物理规律补足了数据缺失），计算快（训练一次，秒级推理）。

快速上手（PyTorch 30行核心）

import torch
import torch.nn as nn

# 1. 定义网络（就是个MLP）
class PINN(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(2, 64), nn.Tanh(),   # 输入: (x, t)
            nn.Linear(64, 64), nn.Tanh(),
            nn.Linear(64, 1)               # 输出: u(x,t)
        )
    def forward(self, x, t):
        return self.net(torch.cat([x, t], dim=1))

# 2. 损失 = 数据损失 + 物理损失
def loss_fn(model, x_data, t_data, u_data, x_pde, t_pde):
    # 数据损失：拟合已知数据
    u_pred = model(x_data, t_data)
    data_loss = ((u_pred - u_data)**2).mean()
    
    # 物理损失：满足偏微分方程（自动微分）
    x_pde.requires_grad_(True)
    t_pde.requires_grad_(True)
    u_pde = model(x_pde, t_pde)
    u_t = torch.autograd.grad(u_pde, t_pde, 
            grad_outputs=torch.ones_like(u_pde), create_graph=True)[0]
    u_x = torch.autograd.grad(u_pde, x_pde, 
            grad_outputs=torch.ones_like(u_pde), create_graph=True)[0]
    u_xx = torch.autograd.grad(u_x, x_pde, 
            grad_outputs=torch.ones_like(u_x), create_graph=True)[0]
    # 一维热传导方程 u_t = alpha * u_xx
    pde_loss = ((u_t - 0.01 * u_xx)**2).mean()
    
    return data_loss + pde_loss   # 两部分一起优化

核心就一句：**用自动微分算出方程残差，把残差当损失。**
