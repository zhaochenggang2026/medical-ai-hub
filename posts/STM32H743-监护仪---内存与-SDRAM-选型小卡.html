STM32H743 监护仪 · 内存与 SDRAM 选型小卡

> **项目归属：公司项目**（非个人产品线，与 BIS-200 / NIRS-400 / NCP-1 无关，勿混淆）。

> 场景：**麻醉深度（BIS，2ch）+ 脑氧（NIRS，6ch）二合一监护仪**，终态 8 通道；数据**实时存内置 SD 卡**；病例回放为**流式**；通过 **LwIP 与医院中控**交换数据；显示用**串口屏**（不占 MCU 显存）。

> 结论速查：**外挂 SDRAM = W9825G6KH-6（256Mbit / 32MB），为扩展预留，不改。**

一、先分清三种介质（最容易混淆）

| 数据 | 性质 | 介质 |

|---|---|---|

| 病例、趋势历史、事件日志、波形存档 | 掉电保留 | **非易失**：内置 SD 卡（或 eMMC）|

| 采集缓冲、处理、回放窗、串口屏队列 | 掉电可丢 | **SRAM（片内）/ SDRAM** |

| 与中控的实时数据流 | 传输中 | 网络（不占长久内存）|

> SDRAM 是易失的，**存不了病例**；病例在 SD 卡，SDRAM 只在「调用/回放」时当工作内存。

二、数据率估算（选型的起点）

• 单通道样本：16bit=2B / 24bit=3B（ADS1299 原始为 24bit）。

• `波形数据率 = 通道数 × 采样率 × 字节数`。

| 配置 | 16bit | 24bit |

|---|---|---|

| 2ch @1kHz（当下）| 4 KB/s | 6 KB/s |

| 8ch @1kHz（终态，上界）| 16 KB/s | 24 KB/s |

> 脑氧（NIRS）通道实际采样率通常低得多，真实值更小；按 1kHz 备的是上界。

> 网络侧压力：8ch ≤ 192 kbps << 100M 以太网，**网络从来不是内存压力源**。

三、各级缓冲（全部落片内 SRAM）

| 缓冲 | 大小 | 说明 |

|---|---|---|

| ETH / LwIP | ~150KB | ST 官方 H743 示例：PBUF 池 ~19KB + 堆 ~128KB，放 **D2 SRAM** |

| 采集 UART RX 环（DMA）| 64~256KB | 吸收「到达 vs 处理」的时间差；8ch 用大些 |

| SD 写缓冲 | 128~256KB | **吸收 SD 卡 GC/磨损均衡的写抖动**（否则丢帧）|

| 串口屏 TX/RX 队列 | 8~32KB | 显示数据即用即弃，不缓存 |

| 应用/任务/栈堆 | 300~500KB | BIS 频谱/双谱、NIRS 解调滤波等 |

→ 片内合计 ~0.7~1.4MB，基本吃满 H743 的 ~1MB 内部 SRAM。**SDRAM 用途只剩「回放窗 + 余量」。**

四、回放窗（唯一真正占用 SDRAM 的项）

回放窗(B) ≈ 回放数据率(B/s) × 窗口时长(s) × 1.5(余量)

• 回放模式：**流式**（边读 SD 边放）→ 窗 = 当前屏 + 前后几屏，**与病例总长无关**。

• 本机型：8ch **流式** → 回放窗 **1~3MB**。

| 回放模式 | 回放窗（8ch 原始）| 说明 |

|---|---|---|

| **流式（采用）** | **1~3MB** | 从 SD 顺序读，窗只要几屏 |

| 整段预载（未采用）| = 病例时长（≤5min≈7.2MB）| 一次读完、秒级定位 |

五、补传：从 SD 读，不占 RAM

数据实时落 SD → **断网期间波形已在 SD 上** → 网络补传**直接从 SD 读重发**，**无需专门的 MB 级 RAM 补传缓存**。

> 前提：断网瞬间不需网络侧零间隙续传；一般补传可接受短暂延迟。

六、SDRAM 选型结论

• 需求：回放窗 1~3MB + 片内余量 → **8MB 即达标**。

• **实配：W9825G6KH-6（256Mbit / 32MB，16bit，54-pin TSOP-II）**——即正点原子阿波罗 H743 的型号。

• 为什么 32MB 不嫌大：

• 单价几块钱，8MB↔32MB 差价可忽略；封装/引脚相同，缩不了板面；

• **为扩展预留**（BIS 2ch → +脑氧 6ch = 8ch，以后还可能加 GUI / 预载回放）；

• **沿用阿波罗已验证的参考设计** → FMC 引脚映射、SDRAM 时序、MPU 配置全现成，省掉自研 bring-up 的坑。

• 量产/医疗注意：选**工业级温度档**（-6I 等）、关注**长期供货 + 第二货源**（IS42S16400、MT48LC16M16 同规格）。

七、铁律与坑（与容量无关，但必须守）

1. **安全相关链留片内 SRAM**：BIS 为辅助决策三类，采集→处理→报警必须走片内；SDRAM 只放回放/历史。外部存储器**不得进安全关键路径**（写进风险管理 ISO 14971 / 注册文档）。

2. **DMA 可访问性**：H7 的 ETH 与 DMA1/2 **访问不了 DTCM（0x20000000）**。ETH 描述符/缓冲、采集 RX、回放 DMA 缓冲一律放 **D1 AXI SRAM（0x24000000）或 D2 SRAM（0x30000000）**。

3. **缓存一致性**：SDRAM / 带 cache 区域的 DMA 缓冲要 **32 字节对齐** + 配 MPU（非缓存或 write-through）+ 收发前后维护 cache。

4. **别把 ETH 缓冲放 SDRAM**：ETH 在 D2、FMC 在 D1，跨 D1↔D2 桥有延迟，100M 突发下会拖累实时性。
