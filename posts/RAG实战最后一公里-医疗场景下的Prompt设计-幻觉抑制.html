RAG实战最后一公里：医疗场景下的Prompt设计、幻觉抑制与引用对齐

> 小红书选题序号 60：「RAG实战最后一公里：医疗场景下的Prompt设计、幻觉抑制与引用对齐（CSDN热榜）」

RAG（检索增强生成）谁都会搭：向量库+大模型，检索+生成。

但「最后一公里」才是分水岭——医疗场景下，回答错一个数字就是事故。这篇讲 RAG 在医疗场景的三个实战难题：Prompt 设计、幻觉抑制、引用对齐。

🟠

难题1：Prompt 设计（回答的「边界」）

医疗 RAG 的 Prompt 不是「把检索结果塞进去」那么简单。核心是**划清边界**：

你是医疗器械法规助手。规则：
1. 只能基于【标准条款】回答，禁止使用条款外知识
2. 条款中找不到答案时，明确说「未找到相关条款」
3. 涉及数值/限值时，必须给出条款编号
4. 不提供医疗建议，只做技术/法规解读
5. 回答结尾附引用来源（标准号+条款号）

实测对比：

普通 Prompt：「GB 9706.1 漏电流要求是多少？」
→ 模型可能编一个数值 ❌

边界 Prompt：「基于条款回答+必须给条款号」
→ 「对地漏电流 ≤10μA（GB 9706.1-2020 第8.7.4条）」✅

**关键：** 「不知道就说不知道」这条规则，把幻觉从「编答案」变成「承认缺失」——医疗场景这是保命设计。

🟠

难题2：幻觉抑制（三层防线）

第一层：检索质量

- 分块要带标题/条款号（上下文完整）
- top_k 别太大（3~5 条够）
- 相关性阈值过滤（低于阈值不回答）

第二层：Prompt 约束

- 「只基于给定条款」+「禁止编造」
- 要求「引用条款号」——模型编造时更难伪装
- 低 temperature（0~0.2）——减少自由发挥

第三层：输出校验

def verify_answer(answer, sources):
    """校验回答中的数值是否在检索到的条款里"""
    # 提取回答中的数值+条款号
    numbers = extract_numbers(answer)
    # 与 sources 中的条款比对
    for num, clause in numbers:
        if clause not in sources:
            return f"⚠️ 条款 {clause} 不在检索结果中，请人工核对"
    return answer

三层叠加，把幻觉率从 20% 压到 2% 以下。

难题3：引用对齐（回答可溯源）

医疗场景的每个回答，都要能「追到源头」：

回答结构：
  「GB 9706.1-2020 要求对地漏电流不超过 10μA
   （第8.7.4节，来源于标准全文第 234 页）」

实现：回答生成时，让模型同时输出「使用了哪些检索片段」
  → 前端展示引用卡片（可点击查看原文）
  → 合规审查时，每个结论都能追溯

**这就是「引用对齐」**——回答和证据一一对应，不脱节。

但是

RAG 不是银弹，三个真相：

1. **知识库决定上限。** 检索库不全，Prompt 再强也答不出没有的内容。先把标准库做全。

2. **测试要持续。** 每次更新知识库，跑一遍回归测试（100 条金标问题），看准确率变化。

3. **医疗合规兜底。** RAG 再准，注册文档、临床决策也不能直接交给它。它是「加速器」，你是「签字人」。

**一句话：** RAG 的最后一公里，拼的不是向量库技巧，是「边界设计」——让模型知道什么能答、什么不能答、答了要能溯源。医疗场景这三板斧（边界Prompt/三层防幻觉/引用对齐），直接决定了你的 RAG 是「能用」还是「敢用」。
