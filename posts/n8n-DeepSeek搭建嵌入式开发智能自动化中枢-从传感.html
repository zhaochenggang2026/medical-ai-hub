n8n 是什么（30秒）

n8n 是一个可视化的工作流自动化工具（类似 Zapier，但开源免费、可自托管）。

它能把不同系统串起来：收到邮件 → 触发 → 调 API → 写数据库 → 发通知。**不需要写代码，拖拽连线就行。**

医疗研发场景它特别合适：数据合规（自托管，数据不出服务器）。
