BCI-100 P0.5 最小采集板 原理图设计

> 目标：一版**可打样**的 ADS1299 最小采集板，配合 P0 固件（`Outputs/5-代码库/BCI-100_ADS1299_P0/`）跑通 P0-2/3/4。

> 依据：TI ADS1299-x datasheet **SBAS499C Rev C** §6 引脚、§9.6 寄存器、§10.2 Figure 72/73、§11.1/11.2 Figure 77（单极供电）、§12 Layout。

> 上游：[[BCI-100_P0硬件验证清单]] ｜ 固件：`Outputs/5-代码库/BCI-100_ADS1299_P0/`

> 形态：40×30mm 方形，4 层（最低 2 层可跑，见 §7）。

0. 本板定位

• **只做采集前端**，不做头环、不做无线、不做电池。供电/主控/上位机全部外部（Nucleo + 台面电源）。

• 目标是把「电极 → 输入网络 → ADS1299 → SPI」这段**布局敏感**的模拟电路先做对，为 G5 正式头环板趟路。

• 全部器件走**嘉立创(JLC)可采购/可 SMT** 的通用料。

1. 供电拓扑（对应 §11.2 Figure 77，单极 5V + 3.3V）

 外部干净 5V ──LC(铁氧体+10uF/0.1uF)──┬── AVDD (19,21,22,56)
 (台面电源/USB)                        └── AVDD1(54)  ← 星型连到 AVDD 网络
 3.3V LDO ──────────────────────────────── DVDD (48,50)
 AGND = AVSS(20,23,32,57) + AVSS1(53)(星型)    DGND = DGND(33,49,51)
 [AGND 与 DGND 在 ADC 下方单点汇合]

**关键点（datasheet §11 原文要求）**：

• **AVDD1 星型连 AVDD，AVSS1 星型连 AVSS**（AVDD1 供电荷泵，带 fCLK 瞬态，必须星型 + 独立退耦）。

• 每个电源脚 **10µF + 0.1µF 陶瓷**就近退耦；**退耦电容与芯片之间禁止打过孔**（同层就近）。

• 数字回流不跨模拟回流路径（布局分区，见 §7）。

• 5V 源：P0 台面验证优先用**低噪线性电源**；若只能 USB，务必 USB 隔离 + LC/铁氧体。

**参考源**：用**内部基准**（CONFIG3.PD_REFBUF=1），VREFP/VREFN 只做退耦，不外加基准芯片。

每路（n=1..8）：`电极焊盘 → R_Filt(串) → ESD → INnP/INnN`，差分 `C_Filt` 跨 INnP–INnN。

| `SRB2` | 18 | 第二参考，未用可悬空 |

**输入网络起始值（工程取值，P0 实测调整，非 datasheet 定值）**：

• R_Filt = 10kΩ（串，每输入端）

• C_Filt = 1.5nF（差分级间，C0G/NPO）；可选每端对 AGND 小容（如 220pF）抑制共模

• 保护：每输入端 TVS/低漏电 ESD（如 SP0503 / 低容 TVS），漏电流要小（EEG 输入阻抗 >10MΩ）

4. 布局规则（§12，本板硬要求）

• **分区**：模拟区（ADS1299 + 输入网络 + VCAP/VREF）｜数字区（SPI/控制）｜电源区（铁氧体/LDO）分离；SPI 线远离模拟输入。

• **地**：AGND/DGND 可分开铺铜，**在 ADC 下方单点汇合**；信号层空白区铺地。

• **退耦就近**：10µF+0.1µF 紧贴电源脚，**退耦电容与 IC 之间不打过孔**。

• **差分输入**：INnP/INnN 走线等长、成对、两侧地包；差分电容用 C0G/NPO 紧贴输入脚。

• **VCAP**：VCAP1(100µF) 足量铜/低 ESR，按 §11 若振动场合换钽。

• **星型**：AVDD1/AVSS1 从 AVDD/AVSS 星型引出。

6. 与固件的接口约定（照 P0 固件写）

• SPI **Mode 1**（CPOL=0, CPHA=1），MSB first；P0 建议 **1~4MHz**（多字节命令间满足 tSDECODE）。

• CS 低有效整帧；DRDY 下降沿读帧（27 字节）。

• 复位：RESET 脚或 RESET 命令后等 ≥ tPOR（≈2^18 tCLK）。

• 寄存器值（固件已锁定）：CONFIG1=0x96(250SPS)、CONFIG3=0xEC(内部基准+bias)、CHnSET=0x50(增益12)。
