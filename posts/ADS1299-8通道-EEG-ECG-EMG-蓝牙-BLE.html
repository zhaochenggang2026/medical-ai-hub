一、项目概述

客户需求为基于 TI ADS1299 的 8 通道生理电信号（脑电 EEG / 肌电 EMG / 心电 ECG）无线采集系统，主要形态约束如下：

• **核心架构**：8 路同步采集 ADS1299 模拟前端 + MCU + **蓝牙 BLE 5.0 无线传输（GATT Notification 流）**。

• **板卡尺寸与布局**：**优先 5cm×6cm**（5×5cm 为备选，正面布板紧张，见 R2）。正面布置全部主芯片（ADS1299、MCU、**BLE 芯片**）、总开关、Type-C 充电口、**8 只 3.5mm 音频插座**（穿板安装，正面 4 + 背面 4，经音频线连电极）及调试下载口（UART：GND/TX/RX/3.3V；SWD：3.3V/CLK/DIO/GND）；背面仅放锂电池（经 PH2.0 类小封装连接器插接）及少量器件。

• **核心指标**：采样率 250/500/1000/2000SPS 可选（上位机指令在各档位间设定；**上位机最高档经客户定为 2000SPS**，原需求所列 4000SPS 不再作上限）；端到端延迟 <20ms；通道间同步误差 <1μs 并以硬件中断打时间戳；3.7V 锂电池供电带充电；**双极导联（8 通道差分对）**；输入阻抗 500MΩ（带 lead-off 口径）；最小检测信号 0.536μV（增益 1 时 1 LSB，量化分辨率）；输入参考噪声 1μVpp（70Hz 带宽，增益 24）；CMRR −110dB；SNR>50dB；频率响应 0.68Hz~70Hz（以 10Hz 为基准，误差 +5%~−10%）。

二、指标可达性逐项评估

| 序号 | 需求指标 | 实现依据 | 结论 |

|---|---|---|---|

| 1 | 8 路同步采集 | ADS1299 为单芯片 8 通道 24 位同步采样 ΔΣ ADC，通道间本质同时采样 | 满足，优于 <1μs |

| 2 | 采样率可调（上位机最高档 2000SPS） | ADS1299 支持 250~16000SPS，由 CONFIG1 的 DR 位在**离散档位**间切换（250/500/1k/2k/4k/8k/16k）；**实际上限由客户上位机最高档定为 2000SPS**（硬件可至 4k 以上，留余量） | 满足 |

| 3 | **蓝牙 BLE 传输、端到端延迟 <20ms** | **上位机最高档 2000SPS → 8ch×24bit×2000SPS≈0.38Mbps，加协议开销约 0.5Mbps**。**BLE 5.0（2M PHY + DLE）应用吞吐约 700kbps~1.4Mbps，从容满足**。定案 **BLE GATT 自定义 Service，Notification 推流，7.5ms 连接间隔**，端到端 <20ms 可行 | 满足（BLE 已定案，带宽充裕） |

| 4 | 通道间同步 <1μs + 硬件中断时间戳 | ADS1299 /DRDY 引脚中断接 MCU GPIO 打时间戳 | 满足 |

| 5 | 3.7V 锂电池供电带充电 | Type-C + 充电管理 + 电池保护电路 | 可行；**续航须实测验证**（P6） |

| 6 | 双极导联（8 通道差分对） | ADS1299 全差分输入（INxP/INxN）构成双极导联；不使用 SRB1 单极蒙太奇 | 满足 |

| 7 | 输入阻抗 500MΩ（带 lead-off 口径） | 与手册一致：lead-off 电流注入下 DC 输入阻抗 500MΩ；不带 lead-off 的 1000MΩ 为手册典型值，不作承诺口径 | 满足（口径已统一） |

| 8 | 最小检测信号 0.536μV | 4.5V 基准 / 2²³ = 0.536μV，即增益 1 时 1 LSB（**量化分辨率**，非最小可检测；实际下限受噪声≈1μVpp 限制）。增益 24 时 1 LSB≈22nV | 满足（口径已澄清） |

| 9 | 输入参考噪声 1μVpp（70Hz） | 手册典型值（增益 24、250SPS）。**注意**：增益 1 时约 7.6μVpp；且噪声随数据率上升——1000SPS 时约 2µVpp。**EEG 建议 250~500SPS、增益 ≥12** | 有条件满足：见左 |

| 10 | CMRR −110dB | 手册最小 −110dB / 典型 −120dB；整机 CMRR 受布局、电极阻抗失配、屏蔽及**防护串联电阻公差**影响 | 满足（手册口径），需板级保障 |

| 11 | SNR>50dB | ADS1299 SNR≈121dB（增益 12），系统级仍远优于 50dB | 满足 |

| 12 | 频响 0.68~70Hz 误差 +5%/−10% | 需数字滤波（FIR/IIR）+ 模拟前端 RC 配合设计并实测；0.68Hz 下限与基线漂移抑制需权衡 | 可实现，需专门设计验证 |

**帧长建议表（BLE，10ms/帧）**：帧净荷 = 8ch×3B×(10ms×采样率) = 24B×每帧样点数。**BLE 受 ATT 单包净荷上限约束（MTU 247B + DLE 251B → 单包净荷 ≤244B）**，超长帧须分片。

| 采样率 | 每帧样点 | 帧净荷 | BLE 分片（≤244B/包） |

|---|---|---|---|

| 250SPS | 2.5 | ≈60B | 1 包 |

| 500SPS | 5 | ≈120B | 1 包 |

| 1000SPS | 10 | ≈240B | 1 包（≈上限） |

| 2000SPS | 20 | ≈480B | 2 包 |

| 4000SPS | 40 | **≈960B** | 4 包（**上位机不启用，硬件余量**） |

> 均加帧头（帧序号/时间戳/CRC，约 10~16B）。**BLE 下帧按 244B 分片组合**；或缩短帧长（2~5ms）以减小单帧体积、降低时延与丢包容错成本。（原 WiFi 版"单包不分片 <1472B"的表述在 BLE 下不成立，已换口径。）

**总体结论**：除第三节列出的应用级问题外，需求指标体系与 ADS1299 能力高度匹配，方案可行；无线改 BLE 后功耗与续航显著改善。

五、核心器件选型

5.1 选型总表

| 序号 | 物料 | 推荐型号 | 厂商 | 关键参数 / 理由 | 备选 |

|---|---|---|---|---|---|

5.2 MCU/无线架构定案结论（**V3.2 修订**）

无线由 WiFi 改为蓝牙后，架构由"ST + 乐鑫"改为 **"ST + Nordic" 双芯片**：**STM32L476RGT6 主控 + nRF52840 BLE 5.0 模块**。

• **主控选 L4**：滤波负载仅占 CPU <10%（8ch×4000SPS×128tap≈4M MAC/s），80MHz M4F 足够；L4 功耗更低利于续航；后期算法加重可升级同封装 L4+（120MHz）或回退 F405。

• **无线选 nRF52840**：BLE 5.0（2M PHY + DLE）满足吞吐（常规档充裕）；**射频电流比 WiFi 低一个数量级**（nRF52840 TX 0dBm ≈ 6.4mA@DC/DC，vs ESP32-C3 WiFi 峰值 350mA），是本次换 BLE 的核心收益；UART/SPI 桥接主控。

• **代价**：双芯片较单芯片多占约 1~1.5cm²（更需 5×6cm）、器件成本略增；跨芯片链路建议 UART 3~5Mbps 或 SPI。

• **可选进一步优化（推荐评估）**：nRF52840 自带 Cortex-M4F@64MHz，滤波负载占 CPU ~12%（80MHz 时为 <10%）→ 可评估**省掉 STM32 的单芯片一体化方案**，再降功耗/成本/面积（对 5×5cm 布板紧张有利）；代价是应用代码迁移到 Nordic SDK。

• 原单芯片方案（ESP32-S3-WROOM-1）作废存档；原 WiFi 模块（ESP32-C3-MINI-1-N4）退役。

5.3 无线传输实现方案（V3.2 补充）

**结论**：采用**现成 nRF52840 硬件模组 + 自研固件**——硬件模块市面货源充足、免自行开发；**关键在固件**，必须是**自定义 GATT + BLE 5.0 高速参数**，**不能沿用通用"串口透传"模块**。

**为什么不用通用透传模块**：通用串口透传多为 BLE 4.x / 1M PHY / 无 DLE / 固定 ~20B 小包 / 连接间隔慢，实测仅 **几 kbps~几十 kbps**，理论上限亦仅约 250~270kbps；且一般不开放 2M PHY / DLE / 连接间隔 / MTU，无法调到目标速率。本设计峰值需 **~0.5Mbps**（2000SPS×8ch×24bit≈0.38Mbps + 协议开销），通用透传达不到。

**固件要点（自研，复用 BCI-100）**：自定义 GATT Service（Notification 推流）+ **LE 2M PHY + DLE（ATT MTU≥247、单包净荷 ≤244B）+ 连接间隔 7.5ms**。BCI-100 已有同构固件（notify 推流 250SPS×8ch×3B=6KB/s），本项目在其基础上调参升速即可。

**四端速率要求（全链路都须 ≥0.5Mbps，任一环不足即成瓶颈）**：

| 环节 | 要求 | 说明 |

|---|---|---|

| AFE → 主控 | SPI（ADS1299，≥8MHz） | 确定 |

| **主控 → BLE 模组** | **SPI（推荐）或 ≥921600 高速 UART** | UART 460800 baud 有效 ~400kbps 即临界，建议 SPI |

| BLE 空口 | **BLE 5.0 2M PHY + DLE** | 上限 ~1.4Mbps，满足 0.5Mbps |

| BLE 模组 ↔ 上位机 | **上位机 BLE 栈须支持 2M PHY + DLE** | 否则降至 1M PHY（~300~500kbps），对 384kbps 临界 → 须与客户确认 |

> 隐含依赖：**上位机 BLE 栈需支持 BLE 5.0 2M PHY + DLE**（并入 D3）。该能力**与上位机平台强相关**：手机 App（Android/iOS）基本无忧；**Windows PC 蓝牙栈限制较多**——可用**外置 USB BLE 5.x 适配器**（避内置网卡不确定性，但须**真支持 2M PHY** 且**实机实测吞吐**；很多只标"蓝牙 5.0"的 dongle 实际只跑 1M PHY）。**（已定：上位机侧采用外置 USB BLE 5.x 适配器。）**

六、系统数据链路

**信号链**：电极 → 3.5mm 音频插座（8 只）→ ADS1299 8 通道同步采样（增益按模式固定，/DRDY 中断）→ SPI → STM32L476（DRDY 打硬件时间戳，片上分模式数字滤波，按 10ms/帧组帧 + 帧序号/CRC；**BLE 下按 ≤244B 分片**）→ UART/SPI（3~5Mbps）→ **nRF52840 BLE 5.0（GATT Notification 推流）** → 上位机（BLE Central，订阅数据流；丢帧检测标记）。

**电源链**：3.7V 锂电 →（TP4056 Type-C 充电 / DW01A+FS8205 保护）→ 直供 3.3V LDO（数字域）；经 TPS610995 升压 5V → **低噪 LDO + 磁珠/LC 滤波**（模拟域，供 AVDD）。

> **延迟预算（V3.0 新增，V3.2 沿用）**：端到端 <20ms 中，10ms/帧组帧本身占约 10ms，叠加 **BLE 连接间隔（7.5ms）与传输**后逼近上限。缓解：缩短帧长（2~5ms）、减小连接间隔或明确延迟定义边界（见 D2）。

七、功耗与续航估算（**V3.2 重估**）

| 模块 | 典型功耗 |

|---|---|

| ADS1299（8 通道） | 约 40~50mW |

| **nRF52840（BLE 5.0，连接态射频）** | **约 6.4mA TX@0dBm / 6.3mA RX @3V（DC/DC）；+8dBm TX ≈ 16.4mA**（原 ESP32-C3 WiFi 发射平均 约 450~950mW / 120~260mA 等效） |

| STM32L476 主控 + 电源转换损耗 | 约 100~200mW + 15% 转换损耗 |

**系统平均由 WiFi 方案的约 0.8~1.2W 降到约 0.1~0.2W 量级**：800mAh 电池续航**从约 1.5~2.5h 提升到约 15~30h 量级**（视采样率/占空比/连接间隔）。**原"续航 ≥3h 临界"问题基本消解**；主功耗转为 AFE + MCU + 跨芯片链路，而非射频。

> **（V3.2 注）** 续航提升幅度取决于实际数据占空比：**常规 EEG（500SPS，≈96kbps）射频占空比极低，续航最优；EMG（2000SPS，≈384kbps，即上位机最高档）居中，仍在 BLE 带宽从容范围**。以上为估算，**须真机实测**；1000mAh（103040）电池兜底仍建议保留。充电 TP4056 1A 对 800mAh 约 1.2~1.5h 达标。

九、医疗级与科研级方案对比

共同硬件平台（ADS1299 + STM32L476RGT6 + **nRF52840**、电源链路、动态带宽滤波）在两方案下完全一致，差异集中在防护电路、电气安全设计、软件流程与法规路径。

9.1 方案对比总表

| 维度 | 科研级方案 | 医疗级方案 |

|---|---|---|

| 产品定位 | 科研/教学/实验原型，明示"非医疗器械、不用于人体诊断治疗" | 医疗器械（生理信号采集器），NMPA 按第二类管理 |

| 电气安全 | 无 IEC 60601-1 强制要求 | IEC 60601-1：CF 型应用部分，患者辅助电流正常 <10µA/单一故障 <50µA，电介质强度 2×MOPP/4000VAC |

| EMC | 常规信息类 EMC | YY 0505 / IEC 60601-1-2 全项 |

9.2 推荐策略（V3.0 修正）

**P4 产品定位待客户/法规确认**，工程侧采用"**科研级 / 医疗级双兼容**"策略（V1.5 折中思路，较 V2.0"医疗级实装"更稳，避免工程评估替客户定案）：

• 原理图按科研级 BOM 设计，但电极入口**预留除颤防护器件封装位**（串联大功率电阻 + 高压钳位，可 0Ω 起始填充）；

• PCB 板间距/走线间距按 IEC 60601-1 的 2×MOPP 爬电要求预留（约 8mm 对地留量），避免后期改板；

• 软件按 IEC 62304 文档习惯组织，不额外增加开发负担；

• 客户确认为医疗后，仅填充防护器件 + 走注册流程，硬件平台不做大改。

> 提醒：医疗器械分类界定、注册周期与费用为工程师估算，正式立项前须由法规事务负责人确认；本节不构成对注册结果的承诺。

附：关键 datasheet 依据

TI ADS1299（SBAS499C Rev.C）

• **内部基准**：4.5V（VREFP = AVSS+4.5V）；AVDD–AVSS = 4.75~5.25V；DVDD = 1.8~3.6V；**内置 2.048MHz 振荡器**。

• **−3dB 带宽 vs 数据率**：250→65Hz；500→131Hz；1000→262Hz；2000→524Hz；4000→1048Hz；8000→2096Hz；16000→4193Hz。

• **输入参考噪声（gain=24，70Hz BW）**：250SPS ≈ 0.98µVpp（标称 1µVpp）；1000SPS ≈ 1.97µVpp。

• **CMRR** −110dB（min）/−120dB（typ）；**输入偏置电流** 300pA；**增益档** 1/2/4/6/8/12/24；**数据率** 250SPS~16kSPS。

Nordic nRF52840（Product Specification）

• **无线**：Bluetooth 5.0/5.3，支持 **LE 2M/1M/500k/125k PHY**；TX 功率可编程（+8dBm ~ −20dBm）；灵敏度 −103dBm@125k / −95dBm@1M。

• **射频电流（DC/DC @3V）**：TX **6.40mA @0dBm**（16.40mA @+8dBm）；RX **6.26mA** @1Mbps。

• **内核/存储**：Cortex-M4F 64MHz、1MB Flash + 256KB RAM；内置 DC/DC、AES/CCM 加速、USB。

• **BLE 吞吐**：**LE 2M PHY + DLE 理论应用吞吐上限约 1.4Mbps**（实测 700kbps~1.4Mbps，随连接间隔/每事件包数变化）。
