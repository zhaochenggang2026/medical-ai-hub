第2步：数据预处理（1-2天，最耗时）

坑都在这里：

**坑1：类别不平衡。** 病灶样本永远比正常少。处理：加权采样或数据增强（翻转/旋转/缩放）。

**坑2：图像尺寸不统一。** CT是DICOM、X-ray是PNG，尺寸千差万别。统一resize到224×224（ResNet标准输入）。

**坑3：标注质量。** 公开数据集标注也可能有错，先抽样检查。

第3步：加载预训练模型 + 微调（40分钟）

关键：不要从零训练，用 ImageNet 预训练的 ResNet，只改最后一层。

import torch
import torchvision.models as models

# 加载预训练 ResNet18
model = models.resnet18(weights=models.ResNet18_Weights.IMAGENET1K_V1)

# 替换最后一层（你的分类数，比如2类：结节/正常）
model.fc = torch.nn.Linear(model.fc.in_features, 2)

# 只训练最后一层（冻结前面的特征提取层）
for param in model.parameters():
    param.requires_grad = False
for param in model.fc.parameters():
    param.requires_grad = True

为什么冻结前面？因为医疗影像的纹理特征和ImageNet差不多，前面层学到的边缘/纹理已经够用，只微调分类头就能出好效果。这样训练快、不容易过拟合。

但是

两个必须说的现实：

**1. 学术数据集 ≠ 临床可用。** 公开数据集上跑出95%准确率，不代表临床能用。真实场景的数据分布、设备差异、人群差异，都会让准确率暴跌。医疗AI的验证要用真实临床数据。

**2. 医疗AI要过审。** 作为医疗器械，AI诊断软件属于三类（或二类）监管，需要注册+临床评价。自己练手随便，做成产品必须走合规。

所以我的建议：练手用它学技术，产品化之前先想清楚「谁用、怎么验证、怎么注册」。
