二、采集端（硬件）

2.1 生物电前端（核心二选一）

• **方案 A（推荐，一颗全包）**：**ADS1298R**（8ch / 24bit / 内置**呼吸阻抗**测量）——4×EEG + 1×ECG + 1×Resp 一块芯片搞定，BOM 最简。

• 代价：EEG 噪声略逊于 ADS1299（科研级仍够用）。

• **方案 B（EEG 最优）**：**ADS1299**（8ch / 24bit / 超低噪，你们现用）做 EEG+ECG；**呼吸单独**用呼吸带（应变/电感，低频直接进一路 ADC）或独立呼吸 AFE。

• 代价：多一块呼吸前端 + 机械件。

> 建议：**先按 A（ADS1298R）验证**，模块化预留 B。

2.2 主控 + 无线

• **低噪路线（科研级常见）**：**STM32L4/H743 + nRF52840**（或 STM32WB 单芯）——采集与射频分离，噪声低。**H743 直接复用 [[NCP-1 神经重症共用平台设计|NCP-1]] 核心板**。

• **单芯集成路线**：**ESP32-S3**（WiFi+BLE 一体）——省事，但射频与模拟同板，噪声/功耗需评估。

• **固件**：ADS129x SPI 驱动 → 数据打包（通道+时间戳）→ BLE Notify；支持导联配置、上/下采样、阻抗自检。

2.3 其余

• **电源**：锂电 + 充电管理 + 电量计（复用 [[BCI-100 脑机接口设备|BCI-100]] 无线头环方案）。

• **电极**：4×干/湿 EEG（前额头箍）+ ECG 电极 + 呼吸带/阻抗电极。

• **结构**：头箍/前额贴（宋超）。

三、数据链路

电极 → ADS129x(24bit) → STM32(SPI) → 打包(通道+时戳) → BLE → 上位机
                                         └─ 本地缓存(SD/Flash)可选

四、上位机（显示）

• **框架**：**PyQt/PySide + pyqtgraph**（高速实时波形，起步最快）或 **Qt/C++ (QML)**（产品化）。

• **核心功能**：

1. **6 通道实时波形**（环形缓冲，滑动窗口滚动）

2. **通道/导联管理**（开关、增益、偏移、颜色）

3. **数字滤波显示**（EEG 0.5–70Hz 带通 + 50Hz 陷波；ECG 0.05–150Hz；Resp 0.1–1Hz）

4. **连接管理**（BLE 扫描/配对/断线重连）

5. **记录与导出**（CSV / EDF，供后续算法分析）

6. （可选）**阻抗/电极自检**显示、**标记/注释**

• **性能**：6ch × 500SPS × 24bit ≈ 9 KB/s，PyQtGraph 轻松实时；预留多设备/多导联扩展。

五、实现路径（分阶段）

• **P0 打通数据流**：开发板 + ADS1298R 评估板（或现成 ADS129x EVM）→ 采集单通道 → BLE → 上位机出波形。

• **P1 6 路同步**：接 4×EEG+ECG+Resp → 验证同步与噪声 → 上位机 6 通道实时显示 + 滤波。

• **P2 可用原型**：头箍/电极/电源整合，长时记录 + CSV/EDF 导出。

• **P3（可选）**：多设备同步、算法模块（伪迹去除/睡眠分期）。

六、复用与增量

| 项 | 复用 | 新增 |

|---|---|---|

| 前端 | ADS1299 经验（BIS-200/BCI-100/NCP-1） | 呼吸阻抗（ADS1298R 或呼吸带） |

| 主控 | NCP-1 H743 核心板 | 无线/低功耗配置 |

| 无线+电源 | BCI-100 无线头环 | — |

| 上位机 | 已有上位机经验 | 实时多通道 + EDF 导出 |

七、提醒

• **科研级/健康级**，不注册 → 无需算法锁定/证据链；但**电极安规、电气隔离**仍需按生物电采集惯例做。

• 呼吸方案先按 ADS1298R 验证；若要更强 EEG，切 ADS1299 + 呼吸带。
